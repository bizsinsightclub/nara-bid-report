# 나라장터 용역 선별 리포트

조달청 나라장터 입찰공고정보서비스(공공데이터포털)를 매일 수집해,
최근 5일 신규 용역 공고 중 검토할 만한 건을 추린 정적 리포트입니다.

- 리포트: https://bizsinsightclub.github.io/nara-bid-report/
- 매일 자동 갱신됩니다.

## 이 리포트가 하는 일

1. 최근 5일 신규 공고를 수집합니다.
2. 조달청 목록 API로 확인 가능한 신호(계약방법·기술평가 비율·참가가능지역·공공조달 분류·
   사업 규모 등)를 조합해 적합도를 매깁니다.
3. 상위 후보의 **입찰공고문·제안요청서 첨부파일을 실제로 내려받아 본문을 읽고**,
   상호출자제한기업집단 소속 광고대행사가 실제로 입찰에 참가할 수 있는지 확인합니다.
   이 정보는 목록 API에 없고 공고문 본문에만 있습니다.
   - 중소기업·소상공인으로 참가자격이 제한되는가
   - 대기업·상호출자제한기업집단 참여가 제한되는가 (소프트웨어진흥법 제48조 등)
   - 광고대행사가 통상 보유하지 않는 면허·업종 등록을 요구하는가
4. 하나라도 걸리면 추천에서 빼고, 무엇을 왜 뺐는지 근거 문장과 함께 보여줍니다.
5. 브로슈어·영상 제작(제작), 프로그램 개발·플랫폼 구축·VFX/CG(개발)처럼 결과물 제작이나
   기술 구현이 본질인 건은 태그를 붙여 별도 섹션으로 후순위에 둡니다.

## 한계

- **선별 결과이지 판정이 아닙니다.** 적합도는 휴리스틱이고, 참가자격 판정은 모델 출력이라
  틀릴 수 있습니다. 근거 문장을 함께 싣는 이유입니다.
- 첨부파일이 없거나 스캔 이미지 PDF(텍스트 레이어 없음)인 공고는 참가자격을 확인할 수 없어
  "문서 미분석" 또는 "판단 보류"로 표시됩니다.
- 중소기업자간 경쟁제품 지정 여부는 별도 고시 자료로 이 리포트 범위 밖입니다.
- 자체 전자조달시스템을 쓰는 기관의 공고는 나라장터에 등록되지 않으면 수집되지 않습니다.

입찰 참여 여부는 반드시 나라장터 원문을 직접 확인한 뒤 판단하십시오.
